# Hướng dẫn cho Claude

Đọc và tuân theo `AGENTS.md` cùng thư mục. Bắt đầu từ `docs/README.md`.
Web, API và mobile dùng chung repository, giữ nguyên tên `frontend-react`, `backend-dotnet`, `Warrant_App`.
Tài liệu được chia nhóm trong `docs/`; cập nhật đường dẫn khi di chuyển, không đưa cache hoặc Git lồng vào project.
